# Руина — боевая система (доп. режим)

Формализация задачи, план и состояние. Режим включается в **Настройки → «Руина — боевая система»** (`settings.ruina.on`). Пока выключен — приложение работает как обычно: ни одна ветка кода Руины не выполняется (всё за `ruOn()`), данные персонажей/способностей не трогаются.

## 1. Постановка

Друг игрока хочет копию боёвки Library of Ruina поверх картотеки:

| # | Требование | Как реализовано |
|---|---|---|
| 1 | Кубы на скиллах, типы урона / один тип «атака» — переключение в настройках; бонусы по умолчанию диапазоном, плюс влияние пассивок и эффектов на кубы определённого типа | `ability.dice=[{t,min,max}]`; настройка «Кубы урона»; модификаторы «Кубы: рубящий / колющий / дробящий / все атакующие / блок / уклон / все кубы» у техник, способностей, эффектов, статусов |
| 2 | Стаггер как полоска | настройка «Полоска стаггера» (по имени, по умолчанию «Стаггер») |
| 3 | Столкновение «как в Руине» | `ruClash`: кубы по очереди, ничья, победа атаки/блока/уклона, остатки без сопротивления |
| 4 | Односторонняя атака / контр-кубы | `ruOneSided`: цель не ответила → работают только контр-кубы (блок «Руина» на листе) |
| 5 | Масс-атаки индивидуальные и суммарные | `ability.mass = ind | sum` |
| 6 | Свой скилл против чужого: через чат, через карточку на карте, оба скилла у мастера | заявка в чате (⚔ на карточке скилла — лист, «Мой», карточка на карте) → ответ цели → итог; мастер: ⚔⚔ на панели карты |
| 7 | Урон списывать, сопротивления | таблица сопротивлений HP/стаггер по типам в блоке «Руина»; урон и стаггер списываются с полосок |
| 8 | Скорость для инициативы | скорость «мин-макс» в блоке «Руина», трекер бросает из диапазона |
| 9 | Эффекты на кубах (на врага / на себя) | ⚡ у куба: программы «при броске / попадании / победе / поражении», `цель.наложить(...)` / `наложить(...)` |
| 10 | Пассивки с условиями | способность без кубов: «Условие пассивки» (формула) + модификаторы + программы событий (кубы, урон, ошеломление, HP 0, ход, раунд) |
| 11 | Всё доступно в конструкторе | переменные `стаггер`, `ошеломлён`, `раунд`, `куб`, `урон`, `скорость` и их `цель.…` — блоки в палитре «Значения»/«Действия» при включённом режиме |
| 12 | Сомнительные механики — настройками с описанием | ничья, контр-кубы, длительность ошеломления, восстановление стаггера, HP 0, цена скилла, победа блока, уклон |

## 2. Правила (движок `ru*`)

- **Бросок куба**: случайное из `[min, max]` + модификаторы `dice:<тип>` (+ − × =) владельца → не меньше 0.
- **Столкновение** (обе стороны ответили скиллами): первый куб против первого.
  - ничья → по настройке «Ничья кубов» (оба сгорают / переброс / побеждает атакующий);
  - атакующий куб победил → урон HP = значение × сопротивление HP (× множитель, если цель ошеломлена), стаггер-урон = значение × сопротивление стаггера; проигравший куб сгорает;
  - блок победил над атакой → стаггер-урон атакующему = разница кубов или значение блока (настройка «Победа блока»); оба куба сгорают;
  - уклон победил → куб уклонения остаётся против следующего куба, восстанавливает стаггер на значение (настройка);
  - блок/уклон против блока/уклона — ничего, проигравший сгорает;
  - когда у стороны кубы кончились, оставшиеся **атакующие** кубы другой бьют без сопротивления, защитные пропадают.
- **Односторонняя атака** (цель не ответила): атакующие кубы против контр-кубов цели по очереди; победивший контр-куб остаётся (настройка) или сгорает; без контр-кубов — урон напрямую.
- **Масс-атака индивидуальная**: каждый атакующий куб — отдельное столкновение с *первым* кубом каждой цели (или односторонне). **Суммарная**: куб атакующего против суммы первых кубов всех целей; победа — урон всем, иначе «атака отбита».
- **Ошеломление**: стаггер ≤ 0 → статус 💫 «оглушён» на N раундов (настройка), урон ×множитель, стаггер-урон не наносится; когда трекер снимает статус — стаггер восстанавливается (полностью / наполовину / нет — настройка).
- **HP ≤ 0** → статус ☠ «мёртв» (настройка), событие «при HP 0».
- **Цена скилла**: если задана «Полоска цены скиллов», при использовании списывается `ruCost` способности (строго / нестрого — настройка).
- **События** (программы куба `d.p` и пассивок `a.on`): `use` бросок куба, `hit` попадание (есть `урон`), `win` победа, `lose` поражение, `take` получение урона, `stg` ошеломление, `dead` HP 0, начало/конец хода и раунда. В программах: `цель` — противник по кубу, `куб` — значение броска (`куб.мин` / `куб.макс` — диапазон), `урон` — урон попадания, `атакующий` / `защитный` / `рубящий` / `колющий` / `дробящий` / `блок` / `уклон` — тип куба (в `take` — тип ударившего куба).
- **Флаги-модификаторы**: `nullify` — кубы владельца и против него без бонусов/штрафов (Обнуление силы); `noact` — не может разыгрывать страницы (Обездвижен).
- **Условие пассивки** — формула на владельце; пока истинна, действуют модификаторы и программы способности. Защита от рекурсии: внутри вычисления условия другие условные способности считаются неактивными.

## 3. Данные

```
ability: { dice:[{t:'slash'|'pierce'|'blunt'|'attack'|'block'|'evade', min, max, p:{use,hit,win,lose}}], mass:''|'ind'|'sum', ruCost, ruCond, on:{use,hit,win,lose,take,stg,dead,onStart,onEnd,onRoundStart,onRoundEnd} }
character.ruina: { deck:{draw,hand,disc}, used:[abId], speed:'1-6', speedBase, speedEmo, res:{hp:{type:mult}, st:{type:mult}}, counter:[dice], stg:1, emo:{lvl,pos,neg,cnt}, scene:{r, ready, done, dice:[{v, ab, tc, ti, done}]} }
settings.ruina: { mapDice, tokenHud, sceneAuto, deckMode, handStart, drawPerScene, emoDraw, handMax, egoMode, oneTarget, speedDice, stgBreaks, redirect, emoOn, emoThr, emoLight, emoSpeedLv, emoPower, lightRegen, rangedOneSided, on, types(true=3|false=1), hpBar, stBar, blockMode:'diff'|'value', evadeRestore, stgMult, stgRounds, stgRestore:'full'|'half'|'none', tieMode:'both'|'reroll'|'attacker', counterKeep, deadStatus, costBar, costStrict, speedDefault }
chat: { k:'ruina', st:'req'|'ans'|'done', i, req, a:{c,ab,nm,dice,mass}, tg:[{c,n}], paid, tc, ab, hd, ls:[...] }
```

## 4. Клиентские пути (проверено в моке `?mock=dm&demo`)

1. Настройки → включить → карточка правки способности получает блок «Кубы (Руина)», лист — блок «Руина», конструктор — блоки Руины, панель карты — ⚔⚔.
2. Игрок: ⚔ на скилле → цель (выделенный токен / выбор) → заявка в чате → у цели «Ответить скиллом» / «Без ответа» → итог в чате, полоски списаны, статусы повешены.
3. Мастер: ⚔⚔ → оба скилла → итог сразу. «⚡ Разрешить сейчас» на заявке.
4. Трекер инициативы: 🎲 берёт скорость; переход раунда снимает ошеломление и восстанавливает стаггер; раундовые программы пассивок.
5. Карточка скилла на карте: ⚔ на карточке / ПКМ → столкновение.
