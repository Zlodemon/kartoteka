# Картотека DnD — свой сервер

Картотека для своей игры: персонажи, организации, локации, карты, документы, чат, бой. Сайт работает на бесплатном тарифе Google Firebase, программировать не нужно. Нужен компьютер с Windows 10/11 и аккаунт Google.

## Установка (первый раз)

1. Скачайте архив: **[Code → Download ZIP](https://github.com/Zlodemon/kartoteka/archive/refs/heads/main.zip)**.
2. Распакуйте его (правой кнопкой → «Извлечь всё…»). Получится папка `kartoteka-main`, её можно переименовать в `kartoteka`. **Храните эту папку** — она нужна для обновлений.
3. Дважды щёлкните `1_USTANOVKA.cmd` и делайте, что он пишет.

Подробная инструкция с картинками шагов — в файле `INSTRUKCIYA.html` внутри папки.

## Как обновляться

Дважды щёлкните **`2_OBNOVIT_SAIT.cmd`** в своей папке `kartoteka`. Больше ничего делать не нужно — скрипт сам:

1. проверит, есть ли здесь, на GitHub, версия новее вашей, и скачает её;
2. сделает **полный бэкап ваших данных** в папку `backups` (хранятся 20 последних);
3. соберёт сайт с **вашими** настройками и выложит его.

После этого игрокам достаточно обновить страницу (F5).

- **Данные не теряются.** Персонажи, карты, картинки, чат лежат в базе Firebase, а обновляется только сам сайт.
- **Перенастраивать ничего не нужно.** Адрес и ключи вашего сервера хранятся в файле `moi-nastroyki.json` — скрипт его не трогает. Не удаляйте этот файл.
- **Если что-то пошло не так**, на сайте откройте *Настройки → Данные → «⬆ Восстановить из бэкапа…»* (зайти мастером) и выберите последний файл из папки `backups`.
- Нет интернета или GitHub недоступен — скрипт предупредит и выложит ту версию, что уже лежит в папке.

## Если вы ставили самую первую версию (архив, присланный вручную)

У первой версии старый скрипт обновления: он не умеет сам скачивать новое с GitHub. Узнать это просто — при запуске `2_OBNOVIT_SAIT.cmd` нет строки «Проверяю, есть ли новая версия». Переход делается **один раз**:

1. Скачайте **[архив с GitHub](https://github.com/Zlodemon/kartoteka/archive/refs/heads/main.zip)** и откройте его.
2. Зайдите внутрь папки `kartoteka-main` в архиве, выделите **всё её содержимое** и скопируйте в **свою** папку `kartoteka` (ту, где лежит `moi-nastroyki.json`). На вопрос о замене файлов ответьте «Заменить».
3. Запустите `2_OBNOVIT_SAIT.cmd` как обычно.

Ваш `moi-nastroyki.json` в архиве нет, поэтому он останется на месте, и сайт выложится на ваш же сервер со всеми данными. Дальше обновляйтесь только через `2_OBNOVIT_SAIT.cmd`.

> Не копируйте саму папку `kartoteka-main` рядом со своей и не запускайте из неё `1_USTANOVKA.cmd` — это установка нового сервера с нуля. Нужно именно положить файлы **в свою** папку.

## Что лежит в папке

| Файл | Зачем |
|---|---|
| `1_USTANOVKA.cmd` | установка сервера (один раз) |
| `2_OBNOVIT_SAIT.cmd` | обновление: скачать новую версию, сделать бэкап, выложить сайт |
| `3_SMENIT_MASTEROV.cmd` | поменять, чьи почты всегда становятся мастерами |
| `app/` | сама система (заменяется при обновлении) |
| `scripts/` | скрипты установки и обновления |
| `docs/` | подробное описание всех возможностей |
| `moi-nastroyki.json` | появится после установки: ваш проект и ключи. **Не удаляйте** |
| `site/` | собранный сайт (пересобирается сам) |
| `backups/` | бэкапы данных перед каждым обновлением |
