# Что нового

## 2026-09-24 00:45

Карта связей — горячие клавиши:
- Ctrl+клик — выделить несколько, Ctrl+A — выделить всё, Esc — снять выделение
- Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D — копировать, вырезать, вставить под курсор, дублировать
- Del — убрать выделенное с карты (персонажи не удаляются), Ctrl+Z — вернуть (до 30 шагов)
- буфер общий для всех карт связей: объекты переносятся с карты на карту (со связями, статусами, заметками; блок — вместе с содержимым)
- выделенные элементы перетаскиваются вместе; заметка: клик — выделить, двойной клик — открыть
- бинды не срабатывают в полях ввода и открытых окнах; бинды карты мира и редактора формул не затронуты

Бэкап данных:
- в полный бэкап добавлена коллекция wmpriv (приватная видимость токенов) — раньше терялась
- бэкап читает только с сервера и предупреждает, если что-то не прочиталось
- «Восстановить из бэкапа» открывает выбор JSON (раньше — картинок) и показывает ошибки записи
- 2_OBNOVIT_SAIT.cmd сам скачивает новую версию с GitHub и делает бэкап данных перед выкладкой

Также в этой версии (24.09):

- копирование способностей между персонажами (⧉ в блоке «Способности»)
- рамка кадра для картинок (⛶ кадр) — токен, портрет и списки; миниатюры чётче (320px)
- игроки могут создавать персонажей (право «Создавать персонажей»)
